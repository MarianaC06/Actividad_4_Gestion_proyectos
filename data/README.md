Dataset: stanfordnlp/imdb, split test. Fields: text (string, English review), label (integer; 0 negative, 1 positive). The original test split contains 25,000 labeled reviews. Run src/prepare_data.py to create data/imdb_sample.csv (300 balanced examples, seed 42). Source: https://huggingface.co/datasets/stanfordnlp/imdb . Dataset redistribution/license terms must be checked at the source. No raw review text is included in this repository.
